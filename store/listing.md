# Chrome 웹 스토어 등록 자료 (1.0.0)

개발자 대시보드(https://chrome.google.com/webstore/devconsole)의 각 칸에 그대로 붙여 넣을 내용입니다.
이미지는 `node scripts/store-shots.js`로 다시 만들 수 있습니다(`store/images/`).

## 1. 패키지

- 올릴 파일: `dist/kone-base64-decoder-1.0.0.zip` (`npm run pack`으로 생성)

## 2. 스토어 등록정보 (Store listing)

**이름** (manifest에서 자동): 코네 Base64 디코더

**요약** (manifest의 description에서 자동, 132자 이하):

> 코네(kone.gg) 게시물 본문·제목과 글 목록 제목의 Base64 문장을 자동으로 풀어 보여 줍니다. 비공식 확장 프로그램입니다.

**설명**:

```
코네(kone.gg)에서 Base64로 적힌 문장을 볼 때마다 복사해서 디코더 사이트에 붙여 넣을 필요가 없습니다. 페이지를 열기만 하면 읽을 수 있는 글로 자동으로 풀어 보여 줍니다.

■ 풀어 주는 곳
· 게시물 제목과 본문
· 글 목록 제목: 게시판, 검색 결과, 홈 화면 미리보기, 프로필의 게시글 목록
· 댓글은 건드리지 않습니다.

■ 보이는 방식
· 풀린 주소(https://…)는 바로 열 수 있는 카드로 바뀝니다. 복사 버튼과 원문 보기 버튼이 있습니다.
· 풀린 문장은 파란 표시로 보이고, 누르면 Base64 원문을 확인하고 복사할 수 있습니다.
· 두 번 이상 겹쳐 인코딩된 문장도 끝까지 풀어 줍니다.
· 코네의 라이트·다크 모드에 맞춰 보입니다.
· 글 이동, 페이지 넘김, 뒤로·앞으로 가기처럼 새로고침 없는 화면 전환도 따라갑니다.

■ 잘못 풀지 않도록
· 영어 단어, 작품 코드, 해시값, 'HP=100' 같은 일반 글은 그대로 둡니다.
· 읽을 수 있는 글자로 풀리는 경우에만 바꾸고, 이미지 같은 바이너리는 풀지 않습니다.
· 코드 블록 안의 짧은 문자열은 그대로 둡니다.

■ 켜기·끄기
툴바의 확장 아이콘을 눌러 자동 디코딩을 켜고 끌 수 있습니다. 바꾸면 열려 있는 코네 탭에 바로 적용됩니다.

■ 개인정보
· 모든 처리는 브라우저 안에서만 이루어지며, 어떤 정보도 외부 서버로 보내지 않습니다.
· kone.gg 페이지에서만 동작합니다.
· 저장하는 정보는 켜기·끄기 설정 하나뿐입니다.

이 확장 프로그램은 코네(kone.gg)와 관계없는 비공식 도구입니다.
```

**카테고리**: 생산성 → 도구 (Productivity → Tools)

**언어**: 한국어

**그래픽 자료**:

| 칸 | 파일 | 크기 |
| --- | --- | --- |
| 스토어 아이콘 | `icons/icon-128.png` | 128×128 |
| 스크린샷 1 | `store/images/screenshot-1-post.jpg` | 1280×800 |
| 스크린샷 2 | `store/images/screenshot-2-list.jpg` | 1280×800 |
| 스크린샷 3 | `store/images/screenshot-3-dark.jpg` | 1280×800 |
| 작은 프로모션 타일 | `store/images/promo-small-440x280.jpg` | 440×280 |

스크린샷의 게시물·목록은 예시 내용으로 만든 화면이고, 실제 코네 게시물은 쓰지 않았습니다.

**공식 URL / 홈페이지 URL / 지원 URL**: 비워 둡니다(저장소가 비공개).

## 3. 개인정보 보호 관행 (Privacy practices)

**단일 목적 설명**:

```
kone.gg 페이지에 적힌 Base64 인코딩 문장을 찾아, 읽을 수 있는 글로 디코딩해 그 자리에 보여 줍니다.
```

**권한 사용 이유**:

- `storage`
  ```
  자동 디코딩 켜기·끄기 설정 하나를 저장하고, 설정이 바뀌면 열려 있는 코네 탭에 바로 적용하기 위해 사용합니다.
  ```
- 호스트 권한 (`https://kone.gg/*`, 콘텐츠 스크립트)
  ```
  kone.gg 페이지의 게시물 제목·본문과 글 목록 제목에서 Base64 문장을 찾아 디코딩 결과를 표시하기 위해 이 사이트에만 콘텐츠 스크립트를 넣습니다. 다른 사이트에서는 동작하지 않습니다.
  ```

**원격 코드 사용**: 아니요. 모든 코드는 패키지 안에 있습니다.

**데이터 사용**: 아무 항목도 체크하지 않습니다(사용자 데이터를 수집하지 않음). 아래 세 가지 준수 사항에는 모두 체크합니다.

- 승인된 사용 사례 외의 목적으로 사용자 데이터를 제3자에게 판매하거나 전송하지 않습니다.
- 항목의 단일 목적과 관련 없는 목적으로 사용자 데이터를 사용하거나 전송하지 않습니다.
- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않습니다.

**개인정보처리방침 URL**: 수집하는 사용자 데이터가 없으므로 필수가 아닙니다. 비워 둡니다.

## 4. 배포 (Distribution)

- 공개 범위: 공개(Public) 또는 미등록(Unlisted, 링크를 아는 사람만 설치) 중 선택
- 지역: 모든 지역 (또는 대한민국만)
- 가격: 무료

## 5. 심사 참고 사항 (Test instructions, 선택)

```
No login is required. Open any post on https://kone.gg/s/somisoft that contains Base64 text (for example a line like "링크: aHR0cHM6Ly9..."). The extension replaces the Base64 text with the decoded result (a link card for URLs, a highlighted span for text). Click the toolbar icon to turn automatic decoding on or off.
```
